# PetTag / tegNFC

Primeira versão visual do sistema de identificação de pets por NFC.

## O que já existe
- Landing page pastel
- Cadastro/login (interface)
- Painel
- Cadastro de pet (interface)
- Perfil público de pet
- Estrutura pronta para conectar backend e banco

## Próxima etapa
Conectar:
- Supabase/PostgreSQL
- Autenticação real
- Upload seguro de fotos
- Tags NFC com token único
- Código de ativação de uso único
- Reutilização segura da tag
- Exclusão de perfil
- Botão "Encontrei este pet"
- Proteções de autorização e privacidade

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000
